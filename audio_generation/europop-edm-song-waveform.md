Compose and produce a Europop EDM song in Waveform using available instruments and samples, with detailed arrangement, effects, automation, mixing, and mastering.

## When to use

Use when asking an AI assistant to create a complete Europop EDM track in Waveform, with creative freedom over instruments and a focus on catchy melodies, dramatic drops, and detailed production.

## Inputs

This prompt has no placeholders. Before running it, provide access to the Waveform project and available VST plugins and samples. Optionally specify track length, tempo, reference tracks, and whether vocals are wanted.

## Prompt

```text
Your job is to compose an amazing europop EDM song. Compose the song using any of the VST plugins or samples in my Waveform DAW. You can decide which instruments to use. Be sure to add variations and effects like risers, epic drops, and other elements that make audiophiles weak to their knees. Also include panning, fx automation, and make sure everything is mixed and mastered professionally. It should not sounds very basic or amateur. The drop impact should not sounds very fake. You can use free samples from samplefocus.com. Spice it up with more ear candy, use a catchier melody, and make it sound amazing
```

## Usage notes

- The assistant needs a way to interact with the DAW to carry out the production work.
- The phrase "The drop impact should sounds very fake" is preserved exactly. Before reuse, decide whether you mean an intentionally artificial sound or a powerful, convincing drop, and adjust that sentence if needed.
- Samplefocus.com is an optional sample source named in the original prompt.
